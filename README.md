# StatusCast

**「今スマホで何のアプリを使っているか」「今どんな曲を聴いているか」を自動で外部から確認できるようにする仕組み**です。

例えば、自分のホームページに「今聴いている曲」を表示したり、友達に「今何してるか」を共有したりするのに使えます。

このリポジトリには**サーバー側のプログラム**だけが入っています。スマホにインストールするアプリ本体は、プログラムを書かなくても使えるように、完成品(APKファイル)を配布しています。

> 💡 **困ったときはAIに聞くのも効率的です**
> 「APIから受け取ったJSONを自分のホームページでどう表示すればいいか」「Renderのデプロイでエラーが出た」など、この後の手順でつまずいた時は、ChatGPTやGeminiなどのAIチャットに聞いてみるのもおすすめです。特に**Claude**([claude.ai](https://claude.ai))はコードの読み書きや技術的なトラブルシューティングに強く、エラーメッセージをそのまま貼り付けて聞くだけでも的確な答えが返ってきやすいです。

## 0. まず知っておくと良い言葉(専門用語の説明)

プログラミングが初めての方向けに、この後よく出てくる言葉を先に説明します。すでに知っている場合は読み飛ばしてください。

| 言葉 | 説明 |
|---|---|
| **リポジトリ (Repository)** | プログラムのファイル一式を保管しておく場所。GitHubというサービス上に置かれる |
| **フォーク (Fork)** | 他の人が作ったリポジトリを、自分のアカウントの下に「まるごとコピー」すること。コピー後は自分の好きに使ってよい |
| **APK** | Androidアプリのインストール用ファイル。Windowsで言う「.exe」のようなもの |
| **サーバー** | 24時間動き続けて、リクエストに応じてデータを返してくれるプログラム。今回は無料サービスの「Render」上で動かす |
| **環境変数 (Environment Variable)** | プログラムの外側から渡す「設定値」のこと。パスワードのような秘密の値を、プログラム本体に直接書かずに渡すためによく使われる |
| **API** | プログラム同士がデータをやり取りするための「窓口」。今回で言うと `https://xxxx.onrender.com/status` にアクセスすると、今の状態がデータ(JSON形式)で返ってくる、というのがAPI |
| **JSON** | データをやり取りするときによく使われる、人にも読みやすい文字だけのデータ形式。例: `{"title": "曲名"}` |
| **CORS** | ブラウザがJavaScriptから別のサイトのデータを取得するのを許可するかどうかの仕組み。今回はあらかじめ許可済みなので、自分のホームページから直接データを取得できる |

## 1. 全体の流れ(まず理解しておく)

```
[Androidアプリ(スマホにインストール)]
        │ 30秒おきに「今使ってるアプリ」「今聴いてる曲」を送信
        ▼
[サーバー(Renderで自分専用に動かす)]
        │ 誰でもアクセスして最新情報を取得できる
        ▼
[ブラウザ・自分のホームページなど]
```

必要な作業は大きく2つです。

1. **サーバーを自分用に用意する**(このリポジトリをフォークしてRenderにデプロイするだけ、コード編集は不要)
2. **スマホにアプリを入れて、サーバーの情報を設定する**(APKをダウンロードしてインストールするだけ)

---

## 2. サーバーを用意する

### 2-1. このリポジトリをフォークする

1. このページの右上にある「**Fork**」ボタンをクリック
2. そのまま「Create fork」をクリック
3. 自分のGitHubアカウントの下に、このリポジトリのコピーができる

### 2-2. Renderにデプロイする

1. [Render](https://render.com) にアクセスし、GitHubアカウントでログイン(無料)
2. 画面上部の「**New +**」ボタン →「**Blueprint**」を選ぶ
   (「Web Service」ではなく「Blueprint」を選ぶのが重要です)
3. 先ほどフォークしたリポジトリを選択する
4. 内容を確認してそのままデプロイを実行する
   - このリポジトリには `render.yaml` という設定ファイルが入っていて、必要な設定(合言葉の自動生成など)を自動でRenderが読み取ってくれます
   - コードを書き換える必要は一切ありません
5. デプロイが終わるまで数分待つ(進行状況の画面が表示されます)

### 2-3. 「合言葉」を確認する

このシステムでは、勝手に他の人がデータを書き換えられないように、スマホとサーバーの間で「合言葉」を一致させる仕組みになっています。

1. デプロイが終わったサービスのページを開く
2. 上のタブから「**Environment**」を選ぶ
3. `SHARED_SECRET` という項目があるので、その値をコピーしてどこかにメモしておく
   (ランダムな英数字の文字列です。この値は今後変わらないので、一度メモすればOK)
4. 同じ画面か、サービスのトップページに表示されているURL(例: `https://xxxx.onrender.com`)も控えておく

---

## 3. スマホにアプリを入れる

### 3-1. APKをダウンロードする

このリポジトリの「**Releases**」ページ(右側のメニューにあります)を開き、一番上の最新リリースから `.apk` ファイルをスマホでダウンロードしてください。

### 3-2. インストールする

Androidでは、Google Playストア以外からアプリを入れる際に、許可が必要です。

1. ダウンロードしたAPKファイルをタップ
2. 「この提供元のアプリのインストールを許可しますか?」のような画面が出たら許可する
   (ブラウザやファイル管理アプリの設定から、"インストール許可"をオンにする必要がある場合があります)
3. インストールが終わったらアプリを開く

### 3-3. アプリ内で設定する

アプリを開くと、上から順に入力欄とボタンが並んでいます。

1. **サーバーURL** の欄に、手順2-3で控えたURLの末尾に `/update` を付けて入力
   例: `https://xxxx.onrender.com/update`
2. **合言葉** の欄に、手順2-3でメモした `SHARED_SECRET` の値を入力
3. **送信間隔(秒)** の欄はそのままでもOK(デフォルト30秒。5秒以上の好きな数字に変更可能)
4. 「**設定を保存**」をタップ
5. 「**使用状況アクセス設定を開く**」をタップ → 開いた設定画面で「StatusCast」を探してオンにする
6. 「**通知アクセス設定を開く**」をタップ → 同じく「StatusCast」を探してオンにする
   (これは「今流れている曲」を取得するために必要な権限です)
7. アプリに戻り、「**送信サービスを開始**」をタップ

これで準備完了です。以降、設定した間隔で自動的にサーバーへ情報が送られます。

## 4. ちゃんと動いているか確認する

パソコンやスマホのブラウザで、以下のURLにアクセスしてみてください(手順2-3のURLに置き換えてください)。

```
https://xxxx.onrender.com/status
```

以下のような文字列(JSON)が表示されれば成功です。

```json
{
  "app": {
    "package": "com.example.app",
    "name": "アプリ名",
    "icon": "iVBORw0KGgoAAAANSUhEUgAA..."
  },
  "music": {
    "title": "曲名",
    "artist": "アーティスト名",
    "positionMs": 45000,
    "durationMs": 210000
  },
  "timestamp": 1234567890123
}
```

- `app.name` : 今スマホで開いているアプリの名前
- `app.icon` : そのアプリのアイコン画像(Base64という文字列形式)
- `music.title` / `music.artist` : 今流れている曲のタイトル・アーティスト名
- `music.positionMs` / `music.durationMs` : 曲の再生位置・長さ(ミリ秒)
- 何も再生していない場合、`music` の中身は全部 `null`(データなし)になります

## 5. 自分のホームページなどからデータを使う

CORSという仕組みをあらかじめ許可してあるので、JavaScriptから直接データを取得できます。

```javascript
fetch("https://xxxx.onrender.com/status")
  .then(res => res.json())
  .then(data => {
    console.log(data.app.name);      // 今使っているアプリ名
    console.log(data.music.title);   // 今聴いている曲名
  });
```

アイコン画像をそのまま表示したい場合:

```html
<img id="appIcon" />
<script>
  fetch("https://xxxx.onrender.com/status")
    .then(res => res.json())
    .then(data => {
      if (data.app.icon) {
        document.getElementById("appIcon").src =
          "data:image/png;base64," + data.app.icon;
      }
    });
</script>
```

## 6. よくある質問・トラブルシューティング

**Q. 元のリポジトリが更新されたら、自分のフォーク先にも自動で反映される?**
A. されません。フォークはその時点でのコピーなので、元のリポジトリが更新されても自動では追従しません。最新版を取り込みたい場合は、自分のフォーク先のGitHubページで「**Sync fork**」ボタンを押して手動で取り込み、その後Renderで再デプロイしてください。

**Q. フォークしたら、Releasesの中のAPKも一緒についてくる?**
A. いいえ、付いてきません。GitHubの仕様上、フォークしてもReleasesは空になります。APKは必ずこの元のリポジトリのReleasesページからダウンロードしてください。

**Q. `/status` にアクセスしても表示が遅い/最初エラーになる**
A. Renderの無料プランは、15分ほどアクセスがないとサーバーが自動的にスリープします。次にアクセスがあった時に起き上がるまで、数十秒かかることがあります。少し待ってから再度アクセスしてみてください。

**Q. `/status` の情報が古いまま更新されない**
A. 以下を確認してください。
- スマホ側で「送信サービスを開始」を押し忘れていないか
- 「使用状況アクセス」「通知アクセス」の両方がオンになっているか
- スマホがネット(Wi-Fiやモバイル通信)につながっているか

**Q. 合言葉を変更したい**
A. Renderの「Environment」タブで `SHARED_SECRET` の値を書き換えて保存してください(自動で再デプロイされます)。その後、スマホアプリ側の「合言葉」欄も同じ値に変更するのを忘れないでください。

**Q. アプリがしばらくすると勝手に送信を止めてしまう**
A. Android側の「バッテリー最適化」機能によって、バックグラウンドで動くアプリが止められることがあります。スマホの設定から「アプリ > StatusCast > 電池」で、最適化の対象から外してください。

**Q. 送っている情報は誰でも見られる?**
A. `GET /status` は誰でもアクセスできる公開API(お互い動作確認しやすくするため、あえてこの仕様にしています)。人に知られたくない情報を扱う予定がある場合は、この部分を認証付きに変更することをおすすめします。

## 7. 対応OSについて

- **Android**: 対応(このリポジトリのAPKが動作します)
- **iPhone (iOS)**: 非対応です。iOSの仕組み上、他のアプリの使用状況や再生中の曲を外部から取得する公開の方法が存在しないため、技術的に実現できません。
